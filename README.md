# Atividades 06, 07 e 08 - Sistema de Biblioteca

Resolução da lista de exercícios de Java (POO) e PostgreSQL.

## Atividade 6 - Java

Desenvolvimento de um sistema de biblioteca utilizando os conceitos de Programação Orientada a Objetos (POO), como abstração, herança e polimorfismo. O sistema permite gerenciar livros, revistas, DVDs, usuários e empréstimos.

O código-fonte está disponível na pasta `java/src/`.

## Atividade 7 - Modelagem SQL

Implementação da estrutura do banco de dados em PostgreSQL para o sistema de biblioteca, incluindo criação de tabelas, chaves primárias, chaves estrangeiras, restrições e inserção de dados iniciais.

O script pode ser executado em `sql/atividade7.sql`.

## Atividade 8 - Consultas SQL

Desenvolvimento de consultas SQL para obter informações do sistema de biblioteca, incluindo acervo, empréstimos em aberto, multas por usuário e itens que nunca foram emprestados.

As consultas estão disponíveis em `sql/atividade8.sql`.
